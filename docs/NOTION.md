# 노션 준비 안내 (처음 하는 분용)

KingLand Bureau의 모든 데이터(조직도·업무·보고·대화)는 **내 노션**에 쌓입니다. 앱은 노션을 읽고 쓰기만 하고, 데이터는 전부 내 것입니다. 처음이면 15~20분 걸립니다.

여기서 할 일은 딱 5가지입니다:
```
① 노션 가입 → ② 본부 페이지 만들기 → ③ 통합(열쇠) 만들기 → ④ 본부 페이지에 통합 연결 → ⑤ 열쇠·링크 복사해 두기
```
DB(표)는 만들 필요 없습니다. 설치 중에 `npm run setup:notion`이 자동으로 만듭니다.

> 🔑 **"통합(Integration)"이 뭐예요?** 앱이 내 노션에 들어올 때 쓰는 **열쇠**입니다. 열쇠는 내가 허락한 페이지에만 들어갈 수 있습니다(④). 그래서 노션의 다른 페이지는 앱이 볼 수 없습니다.

---

## ① 노션 가입 (이미 쓰고 있으면 건너뛰기)

1. https://www.notion.so 접속 → **무료로 노션 사용하기 / Get Notion free**
2. 구글 계정 또는 이메일로 가입 → 용도는 **개인용(For myself)** 선택해도 충분합니다.
3. (선택) 앱 설치: https://www.notion.so/desktop — 맥·윈도우 앱, 휴대폰은 앱스토어/플레이스토어에서 "Notion". 웹 브라우저만으로도 모두 할 수 있습니다.

> 💡 **요금제**: 무료 플랜으로 충분합니다. 회사 워크스페이스(Plus/Business 등)를 쓰는 경우 **③ 통합 만들기는 워크스페이스 소유자(Owner)만** 할 수 있습니다. 권한이 없으면 소유자에게 부탁하거나, 개인 워크스페이스를 하나 만들어 쓰세요.

## ② 본부 페이지 만들기

1. 노션 왼쪽 사이드바 아래 **+ 새 페이지(New page)** (또는 사이드바 "개인 페이지/Private" 옆 **+**)
2. 제목에 이름 입력 — 예: `AI SForce 본부` (아무 이름이나 됩니다)
3. 본문은 비워 두세요. 설치 중에 이 페이지 **아래**에 DB 6개가 생깁니다:
   `01 설정` · `02 조직도 및 역할` · `04 AI 공용 업무 DB` · `05 최종 보고서` · `09 업무 보고 이력` · `10 회의실 대화`

> ⚠️ 이 페이지를 나중에 다른 곳으로 옮겨도 괜찮지만, **안의 DB 이름 앞 번호(01·02·04…)는 바꾸지 마세요.** 앱이 번호로 DB를 찾습니다.

## ③ 통합(열쇠) 만들기

1. https://www.notion.so/profile/integrations 접속
   - 노션 앱 안에서는: 왼쪽 위 워크스페이스 이름 → **설정(Settings)** → **연결(Connections)** → 맨 아래 **통합 개발 또는 관리(Develop or manage integrations)**
2. **+ 새 통합(New integration)**
3. 입력:
   | 칸 | 넣을 것 |
   |---|---|
   | 이름 (Name) | `KingLand App` (아무 이름) |
   | 연결된 워크스페이스 (Associated workspace) | ②에서 본부 페이지를 만든 워크스페이스 |
   | 유형 (Type) | **내부 (Internal)** |
   → **저장(Save)** → **통합 구성(Configure integration settings)**
4. **기능(Capabilities)** 확인 — 이렇게 맞추고 **저장**:
   - ✅ 콘텐츠 읽기 (Read content)
   - ✅ 콘텐츠 업데이트 (Update content)
   - ✅ 콘텐츠 입력 (Insert content)
   - 댓글: 꺼도 됨
   - 사용자 정보: **사용자 정보 없음 (No user information)**
5. **구성(Configuration)** 탭 → **내부 통합 시크릿(Internal Integration Secret)** → **표시(Show)** → **복사(Copy)**
   - `ntn_`으로 시작하는 긴 글자입니다. 이것이 **`NOTION_TOKEN`** 입니다.
   - ⚠️ **채팅·메신저·이메일에 붙여 넣지 마세요.** 설치 중에 `.env.local` 파일(내 컴퓨터)과 Vercel 설정 칸에만 넣습니다.
   - 실수로 어딘가에 노출했다면: 같은 화면에서 **새로 고침(Refresh)** 을 눌러 새 시크릿을 받으면 옛 것은 못 쓰게 됩니다.

## ④ 본부 페이지에 통합 연결 ← 가장 많이 빠뜨리는 단계

열쇠를 만들기만 하면 아무 페이지에도 못 들어갑니다. 본부 페이지에 "들어와도 된다"고 허락해 줘야 합니다. 둘 중 편한 방법으로:

**방법 A — 페이지에서**
1. ②의 본부 페이지 열기
2. 오른쪽 위 **•••** (더보기) → **연결(Connections)** → **연결 추가(Add connections)**
3. `KingLand App` 검색 → 선택 → **확인(Confirm)**

**방법 B — 통합 설정에서**
1. ③의 통합 화면 → **액세스(Access)** 탭 → **페이지 선택(Select pages)** 또는 **액세스 편집(Edit access)**
2. 본부 페이지 체크 → 저장

확인: 본부 페이지 **••• → 연결** 목록에 `KingLand App`이 보이면 성공입니다. 상위 페이지에 연결하면 그 아래 DB들도 자동으로 열립니다.

## ⑤ 본부 페이지 링크 복사

1. 본부 페이지 오른쪽 위 **•••** → **링크 복사(Copy link)** (또는 **공유(Share) → 링크 복사**)
2. 이 링크가 **`NOTION_ROOT_PAGE_ID`** 입니다. 링크 그대로 넣어도 됩니다 (앱이 끝의 32자리 ID만 뽑아 씁니다).
   - 예: `https://www.notion.so/AI-SForce-1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d?pvs=4`
   - 링크는 비밀이 아니지만, 공개 웹에 올릴 필요는 없습니다. **페이지를 "웹에 게시"하지 마세요** — 필요 없습니다.

## 설치 중에 이 값들이 쓰이는 곳

| 값 | 넣는 곳 | 언제 |
|---|---|---|
| `NOTION_TOKEN` (③-5) | 내 컴퓨터 `.env.local` → 나중에 Vercel 환경변수 | 설치 인터뷰 STEP 4 · 배포 STEP 7 |
| `NOTION_ROOT_PAGE_ID` (⑤) | 위와 같음 | 위와 같음 |

`.env.local` 여는 법: 맥 `open -e .env.local` / 윈도우 `notepad .env.local` (점으로 시작하는 숨김 파일이라 폴더 창에서 안 보일 수 있어요).

그다음 `npm run setup:notion`을 실행하면 본부 페이지 아래에 DB가 생기고 기본 조직이 채워집니다. 확인할 것:
- 본부 페이지에 `01 설정`, `02 조직도 및 역할` … `10 회의실 대화`가 보이는지
- `02 조직도 및 역할`에 대장 피클(과 참모·에이전트)이 들어 있는지

## 설치 후 노션에서 하면 좋은 것

- **02 조직도 및 역할** — 에이전트마다 `역할`·`강점·역량`을 채우면 대장·참모가 더 알맞게 일을 나눕니다. 쉬게 할 에이전트는 `상태`를 `중지`로.
- **05 최종 보고서** — 일일 보고서가 쌓입니다. 읽은 건 `사단장 확인` 체크.
- **09 업무 보고 이력 · 10 회의실 대화** — 기록 보관용입니다. **지우거나 고치지 마세요** (추가만 하는 기록).
- 휴대폰 노션 앱으로도 같은 내용을 볼 수 있습니다.

## 자주 막히는 곳

| 증상 | 원인 · 해결 |
|---|---|
| 세팅 중 `401 (토큰이 틀렸습니다)` | 시크릿을 끝까지 다시 복사 (앞뒤 공백 없이). 새로 고침(Refresh)했다면 새 값으로 |
| 세팅 중 `404 (통합이 연결돼 있지 않거나…)` | ④를 안 했거나, 링크가 다른 페이지. 본부 페이지 ••• → 연결에 통합이 있는지 확인 |
| 앱에 "DB를 찾지 못했습니다" | `npm run setup:notion`을 아직 안 함, 또는 DB 이름 앞 번호를 바꿈 |
| 앱이 **목업 모드**로 보임 | 노션 키가 앱에 안 들어감. 로컬은 `.env.local` 저장 후 앱 재시작, Vercel은 환경변수 넣고 **Redeploy** |
| 통합 만들기 버튼이 없음 / 권한 없음 | 회사 워크스페이스에서는 소유자만 가능. 소유자에게 부탁하거나 개인 워크스페이스 사용 |
| 연결 목록에 내 통합이 안 보임 | 통합의 "연결된 워크스페이스"가 본부 페이지가 있는 워크스페이스와 다름 → ③에서 같은 워크스페이스로 새로 만들기 |
| 팀스페이스 안 페이지라 연결이 안 됨 | 팀스페이스 권한 문제일 수 있습니다. 개인 페이지(Private)에 본부 페이지를 만들면 가장 간단합니다 |
