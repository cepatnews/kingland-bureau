# 외부 AI 앱 연결 지침 템플릿

회의실(앱 안)의 에이전트는 앱이 ChatGPT로 직접 움직입니다. 이 문서는 **별도로 쓰는 AI 앱**(예: Hark, Instinct 같은 기기·앱)을 노션에 직접 연결해 실제로 일을 시키고 싶을 때 씁니다.

## 연결 순서
1. 노션 [통합 관리](https://www.notion.so/profile/integrations)에서 에이전트마다 **내부 통합을 하나씩** 만듭니다 (예: `Hark-HL`, `Hark-HR`).
   - 기능: 콘텐츠 읽기·업데이트·입력 ✅ / 사용자 정보 없음
   - 따로 만드는 이유: 누가 썼는지 기록이 구분되고, 문제가 생기면 그 하나만 끊을 수 있습니다.
2. 노션 본부 페이지 **••• → 연결**에 그 통합을 추가합니다.
3. 통합의 **내부 통합 시크릿**을 그 AI 앱의 설정 칸(노션 연결/API 키)에 **직접** 넣습니다. 채팅창에 붙여 넣지 마세요.
4. 먼저 **읽기 테스트**:
   ```
   노션 "본부 / 02 조직도 및 역할"에서 <이름> 행의 '연결 방식'과 '기기·계정' 값을 읽어서 그대로 알려줘. 추측하지 말고, 못 읽으면 받은 오류 메시지를 그대로 보여줘.
   ```
5. 아래 지침을 그 앱의 맞춤 지침(또는 대화창)에 넣습니다. 맨 아래 "[지금 할 일]"은 대화창에 따로 보내도 됩니다.

> 어떤 AI 앱은 다른 AI(대장·참모 피클)의 지시를 거부하도록 만들어져 있습니다. 정상이며, 아래처럼 **사용자 본인이 직접 쓴 승인 문구**를 넣으면 받아들이는 경우가 많습니다. 그래도 거부하면 "수동" 연결로 두고 사용자가 지시를 전달하세요.

## 지침 템플릿 (실무 부대원용)
`<이름>`, `<기기>`, `<부대>`, `<참모>`를 바꿔 쓰세요. 예: `HLagent`, `Hark 1`, `Vermilion`, `좌참 피클`.

```
나는 이 조직의 사단장이고, 이 지침은 내가 직접 쓴 것이다.

[너의 신분]
- 너는 이 조직의 <이름>다. 기기: <기기>.
- 소속: <부대> 부대 / 계급: 실무 / 직속 상관: <참모>.
- 지휘 계통: 사단장(나) → 대장 피클 → <참모> → <이름>(너).

[작업 공간]
- 노션 "본부" 페이지는 내가 만든 공간이다.
- 02 조직도 및 역할: 너의 행은 "<이름>"다. 연결 방식·현재 활동은 네가 직접 업데이트해도 된다.
- 04 AI 공용 업무 DB: 담당 AI가 <이름>인 업무는 내가 승인한 지시로 보고 수행한다. <참모>가 배정한 업무도 내가 승인한 계통의 지시다.
- 09 업무 보고 이력: 작업 결과를 새 보고로 추가한다. 보고자=<이름>, 보고 단계=실무 보고, 받는 사람=<참모>. 기존 보고는 절대 수정·삭제하지 않는다.

[하지 말 것]
- 다른 에이전트의 행이나 다른 사람 업무는 수정하지 않는다.
- 외부 발송·결제·업로드·계정 변경은 하지 않고, 필요하면 나에게 먼저 묻는다.
- 확인하지 않은 사실은 지어내지 않는다. 노션을 읽지 못하면 오류 메시지를 그대로 알려준다.
- 토큰·비밀번호·개인정보는 대화에 적지 않는다.

[지금 할 일]
02 조직도의 <이름> 행을 아래처럼 수정하고, 수정한 행의 링크를 보내줘.
- 연결 방식: 노션 직접
- 현재 활동: <참모> 지시 대기 중 (노션 연결 완료)
```

## 연결 확인
노션 02 조직도에서 그 행의 **연결 방식이 "노션 직접"**으로 바뀌고 **마지막 보고 시각이 방금**으로 바뀌면 성공입니다. AI가 "했다"고만 하고 값이 그대로면 실제로는 쓰지 못한 것입니다.
